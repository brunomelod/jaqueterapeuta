# Landing Jaqueline (React + Vite)

## Rodar em desenvolvimento

```bash
cd web
npm install
npm run dev
```

Abra o endereço que o Vite mostrar (geralmente `http://localhost:5173`).

## Build estático

```bash
npm run build
```

Saída em `web/dist/`. O motor **Sites Incríveis** fica em `public/motor/` e é copiado para `dist/motor/` no build.

## Versão HTML pura

A página estática anterior continua em `../public/index.html`.
